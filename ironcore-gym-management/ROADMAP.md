# Roadmap

Potential improvements for future releases:

- [ ] Secure admin login and role-based access control
- [ ] CSRF protection and stricter validation
- [ ] Member check-in / attendance tracking
- [ ] Payment history and downloadable receipts
- [ ] Calendar-aware membership expiry and renewals
- [ ] Trainer-to-member assignment and workout schedules
- [ ] Export member lists to CSV
- [ ] Automated tests for CRUD, validation and database constraints
- [ ] Docker configuration and production deployment guide
